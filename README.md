# Conversor de Dolares a Lempiras

**Estudiante:** Camila Fernanda Nuñez Suazo 

## Descripcion

Aplicacion web de conversor de dolares a lempiras hecha con React, Vite y Material UI 
que convierte dolaresa lempiras usando la tasa de cambio real obtenida
de la API publica ExchangeRate-API. Muestra la tasa actual y calcula el total
en tiempo real mientras el usuario escribe la cantidad que quiere convertir a dolares.

## Como ejecutar el proyecto

1. Clonar el repositorio:
   git clone https://github.com/camilanunez71/conversordolareslempiras.git
2. Entrar a la carpeta:
   cd conversordolareslempiras
3. Instalar dependencias:
   npm install
4. Ejecutar en modo desarrollo:
   npm run dev

## Tecnologias utilizadas

- React + Vite
- Material UI
- ExchangeRate-API (https://www.exchangerate-api.com)
